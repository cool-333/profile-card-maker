# 프로젝트 : 프로필 카드 메이커<br>
디자인 비전공자처럼, 편집 프로그램을 다루는 데에 어려움이 있는 일반인들도 <u>내용 입력만으로 간단하게</u> 자신을 설명하는 프로필 카드를 만들 수 있는 사이트입니다.

## 프로젝트 개요
- 개발 동기 : carrd 같은 자기소개 사이트를 만들 때 하나하나 값을 세팅해주는 것이 번거로워, 레이아웃을 미리 짜 두 고 내용만 입력하면 카드가 나오면 어떨까 하는 생각에 제작하게 되었습니다.
- 개발 기간 : 2026/09/23 ~ 2026/10/05 (평일만 작업, 총 8일)
- 참여 인원 : 1인 (단독 개발)

### 기술 스택
HTML, CSS, JS

### 트러블 슈팅
* 초기 세팅 시 var 함수를 사용하여 배경색을 지정해 두었을 때, 배경색을 팔레트로 바꾸니 테마 버튼까지 색상이 바뀌는 이슈 발생.
  * 테마 색상을 var 함수 대신 색상코드로 지정하여 문제 해결.

* 글자수를 제한하지 않아 입력창 밑으로 줄바꿈되어 내용이 넘치는 이슈 발생.
  * maxlength 기능 이용 및 한글/영어/특수문자/숫자로 입력해보며, 적정한 글자수 제한 탐색하여 문제 해결.

* max값을 100으로 지정했으나, 직접 입력하면 100 초과한 값이 입력되는 이슈 발생.
  * 100을 초과한 값을 입력하면 자동으로 100으로 제한하도록 하여 문제 해결.

### 회고 및 느낀 점
간단해 보이는 사이트를 만드는 데에도 생각보다 많고 복잡한 코드가 들어가고, 그 과정에서 트러블도 많이 일어난다는 것을 알게 되었습니다. 또한 이번 프로젝트를 반응형으로 만들기에 시간이 조금 부족하여 시도하지 못했던 것이 아쉬웠습니다. 기회가 된다면 다른 프로젝트를 만들 때에는 반응형으로 만들고 싶습니다.
